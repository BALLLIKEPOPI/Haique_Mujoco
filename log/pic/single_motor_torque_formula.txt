Single Motor - Torque - Quadratic Fitting Formula
============================================================

F(RPM) = a·RPM² + b·RPM + c

  a = 2.3863485822e-08 N/rpm²
  b = -4.5938429659e-05 N/rpm
  c = 6.4041840279e-02 N

def thrust_N(rpm):
    return 2.3863485822e-08 * rpm**2 + -4.5938429659e-05 * rpm + 6.4041840279e-02

def thrust_g(rpm):
    return thrust_N(rpm) / 0.00981
